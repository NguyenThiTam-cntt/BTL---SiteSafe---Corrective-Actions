---

## Mục đích của trang
Trang web giúp quản lý công trường theo dõi, phân loại và cập nhật tiến độ xử lý các sự cố an toàn lao động tại các khu vực (Zone) thuộc công trình, giúp đảm bảo an toàn lao động và đúng quy trình kiểm định.

---

## Các chức năng chính
1. **Quản lý sự cố trực quan:** Hiển thị danh sách sự cố dạng Bảng Kanban (4 trạng thái: Cần làm, Đang xử lý, Đang nghiệm thu, Đã đóng) và chế độ Xem dạng Danh sách.
2. **Bộ lọc & Tìm kiếm:** Tìm kiếm theo mã/tiêu đề sự cố, lọc theo khu vực (Zone A, B, C, D) và lọc nhanh các sự cố ưu tiên.
3. **Cập nhật trạng thái (Modal):** Nhấp vào từng sự cố để xem chi tiết và chuyển trạng thái xử lý.
4. **Xuất báo cáo:** Xuất dữ liệu danh sách sự cố hiện tại ra file CSV.

---

## Công nghệ sử dụng
* **HTML:** Semantic HTML (`header`, `nav`, `main`, `section`, `article`, `footer`, `aside`).
* **CSS:** Flexbox, CSS Grid, Custom Variables, Media Queries (Responsive).
* **JavaScript:** DOM Manipulation, Event Handling, Array Filtering, Export CSV.
* **FontAwesome:** Tích hợp bộ icon biểu tượng trực quan.
